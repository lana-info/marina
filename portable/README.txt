Marina — portable запуск для Windows

1. Распакуйте весь архив Marina.
2. Откройте папку portable.
3. Дважды щёлкните start-marina.bat.
4. Marina откроется в браузере по адресу http://localhost:8765/

Python, PHP и Node.js не требуются: используется встроенный в Windows PowerShell.
Для остановки закройте окно PowerShell.

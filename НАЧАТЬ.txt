MARINA — КАЛЬКУЛЯТОР ДЛЯ ВЯЗАНИЯ

Как запустить на Windows:

1. Распакуйте весь ZIP-архив в отдельную папку.
2. Откройте папку portable.
3. Дважды щёлкните файл start-marina.bat.
4. Marina откроется в браузере автоматически.

Если браузер не открылся, перейдите по адресу:
http://localhost:8765/

Для работы нужен современный Microsoft Edge, Google Chrome или Firefox.
Internet Explorer не поддерживается.

Важно: не запускайте index.html двойным щелчком. Используйте start-marina.bat.

Для остановки закройте чёрное окно PowerShell.
